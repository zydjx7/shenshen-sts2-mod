# 角色美术与动画（2026-11-05）

## 已确认的外形

用户从三版粉色候选中选择 P1「樱粉圣光」：金发刘海、侧马尾、白粉金衣裙、披风和太阳法杖。照片仅作面容与发型参考，未加入仓库。后续指定肤色更白、小腿略长、胸部略丰满，保持自然、不夸张；不将生成提示中的百分比视为已确认的精确人体参数。

用户明确要求角色像原游戏一样能动。外形概念稿本身是静态参考，不能用来声称动画已经完成。选定修订稿保存在 `Shenshen/images/character_forms/human/p1/revised-design.png`；两套分件图集和定位清单位于各自的 `human/p1/`、`cat/p1/`。

猫形以金色毛发、粉色蝴蝶结与白粉披肩制作配套临时原型，用于让变身实际改变轮廓；猫的具体造型仍未最终确认。少女和猫互斥，不同时渲染成角色与伙伴。

## 动画接入

以本机游戏 0.111.0 和锁定 BaseLib 3.4.7 实际程序集为依据。原版 `CreatureAnimator` 依赖 Spine；本项目不冒充 Spine 骨架，使用 BaseLib 已有的非 Spine `CustomAnimation` 桥接，通过原生 Godot `AnimationPlayer` 驱动多个 Sprite2D 分件。

`ShenshenVisuals` 构造 `NCreatureVisuals` 所需 Bounds、中心、意图和特效节点，按 JSON 清单的父子关系、枢轴与 AtlasTexture 区域装配。图集中的多个矩形区域只是取材范围，透明背景由 PNG alpha 保留；不按预览器中残留 RGB 背景判断是否透明。

- Idle：躯干轻微呼吸、头部与马尾、披风和袖臂独立运动，睁闭眼切换。
- Attack：持杖手臂与上身动作，法杖跟随手臂，攻击延迟与角色的 `AttackAnimDelay` 对齐。
- Cast / PowerUp：施法手势和局部光效；非攻击技能显式发出 Cast 事件，不更改卡牌数值与牌堆。
- Hit：受击后仰与短暂闭眼；Dead：倒下并停在末帧；Revive 回到待机。
- BaseLib 不替非 Spine 场景初始化待机或自动返回待机。本控制器在 Ready 启动 Idle，单次动作结束后回返，死亡动作除外。死亡等待使用角色的 `DeathAnimTime`。
- 形态外观由实际 FormPower 决定；换形只切换视觉容器，不复制战斗模型、卡牌或状态。

选人背景、头像、选人按钮和地图标记是独立资源，不能仅替换战斗形象后就认为所有入口都已更新。原游戏选人按钮和地图标记 getter 要求 CompressedTexture2D；BaseLib 只替换路径，不能给这些路径返回 AtlasTexture。UI 使用导入 PNG：头像为独立生成的 `avatar.png`，选人按钮为选定全身设计稿；自建选人背景使用普通 Control 场景。战斗分件内部可使用 AtlasTexture，不受上述 UI getter 限制。

## 素材来源与验证边界

本轮使用内置 image_gen 生成与编辑，提示保存在 [生成记录](art-prompts-2026-11-05.json)。选定素材进入仓库；候选稿和用户预览保存在本机 outputs，原始生成文件保留。未使用不同版本教程替代本机 API 核对。

验证分为真实程序集动作桥接、Godot 图形渲染、构建打包和游戏界面实测。当前阶段的最终结果以 [Windows 验证记录](windows-validation.md) 的追加记录为准。Mac 和真实多人两端的动画同步尚未验证；分件动作仍是首版，可继续打磨关节遮挡、节奏与特效。

本轮独立 GPU 渲染检查了少女/猫的待机、眨眼、施法、攻击和受击，并录制 10.53 秒真实运行预览。专用游戏启动时暴露选人按钮的 AtlasTexture 类型错误，随后按本机 API 改用 PNG 并补充真实 getter 回归；最终编译打包、95 项回归与真实游戏 headless 启动均通过，强制转换异常消失。首次获取窗口时用户按 Esc 停止电脑自动操作，本轮没有取得游戏内新角色截图、没有打出动画卡牌。不得将独立预览或无窗口启动称为游戏实战通过。

休息点、商店角色、多人手势、能量球和过渡材质等仍继承模板资源；原版 Spine 专用低血量表现与液体覆盖等效果尚未适配。当前替换范围是战斗双形态、选人背景、头像/按钮和地图标记。
