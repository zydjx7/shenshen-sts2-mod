# 光之魔法少女深深

《杀戮尖塔 2》原创角色模组，供个人使用。内部工程、程序集及模组 ID 统一为 `Shenshen`；目录名称可不同，两台电脑使用同一仓库。

角色有人形、猫形两种互斥形态，规则见 [角色设计](docs/character-design.md)。Windows 接续已实现独立卡池、两套实际持有的基础牌与变形换牌。当前是开发原型；各项代码、构建与实测范围见 [Windows 验证记录](docs/windows-validation.md)。

当前少女静态外形已确认「B5-3 日轮圣像／柔和饱满」：粉白金斗篷、太阳帽与法杖、裸足、奶油白金短发、白皙肤色，帽影遮脸只露下巴，保留自然饱满的脚踝；幼猫沿用指定原图的四足间距、舒展身体与聪明神态。新战斗视觉使用连续 Godot 二维网格动画，保持完整袖口和爪部的原画连接，包含待机、施法/挥爪、攻击、受击与双形态切换。战斗使用原图和独立日轮，HUD／地图头像保留 B5 头部；选人背景与小卡面已改用「杏桃晨金」独立确认稿；火球发射点随法杖移动。该美术接入版本曾编译打包并通过 451 项回归，独立 Godot 录像已完成；当时用户要求先看录像，真实战斗逐项验收延期。这些历史结果不覆盖本轮蓝卡和商店修改。制作来源与分层验证见 [B5 接入记录](docs/art-solar-b5-2026-11-06.md) 和 [角色美术与动画](docs/character-art.md)。

## 使用

Mac：

```sh
./tools/bootstrap.sh
./tools/build.sh build
./tools/build.sh pack
```

Windows：

```powershell
./tools/bootstrap.ps1
./tools/build.ps1 build
./tools/build.ps1 pack
```

默认只向 `dist/` 输出，不改 Steam 设置、游戏安装目录或存档。`dist/Shenshen/` 包含本模组，`dist/BaseLib/` 包含匹配的运行依赖。游戏退出后，才可按需将这两个目录复制到游戏的 mods 目录进行测试。

此前版本的 Windows 编译、资源打包及 420 项真实程序集/Godot 回归通过。专用游戏窗口曾复验双面变形卡的目标图像与收益、咪挡名称、变猫当回合闪避，以及变回少女时隐藏闪避图标；既有主要动作、火球与选人立绘另有历史验收记录。该次游戏正常退出后 1036 个日常文件哈希不变。这些历史结果不覆盖本轮 40 张蓝卡、去除回血与商店模型修改。当前保存沿用原版战前/房间边界，不恢复战斗中途快照。HeftyTablet 的金卡奖励已有深深的角色金卡可供选择；更长流程、双端多人和 Mac 新代码仍待验证。完整范围及已知问题见 [Windows 验证记录](docs/windows-validation.md)，日常协作见 [开发说明](docs/development.md)。

2026-11-06 的新起始牌组、印记逐段附伤、甩尾和全部升级已实装，已部署并启动全新的专用测试局，游戏界面确认 18 张永久牌及新牌加载；用户随后反馈实战试打卡牌未发现问题。此反馈与 174 项自动回归分别记录，完整边界与平台验收继续推进。变身魔法现为真实基础牌，可在原版普通锻造选牌中升级，保存并继承到后续战斗；开场额外移手，不占正常 5 抽。炸毛基础仅首次敌方攻击扣血获得 3 荆棘，升级后才解锁后续扣血与敌方负面各加 1，费用均为 1。印记的时限、施加者范围及固定格挡等实现选择见 [角色设计](docs/character-design.md)。

## 目录

- `ShenshenCode/`：角色、独立卡池、原创牌、形态与战斗机制。
- `Shenshen/`：角色资源和 `localization/eng`、`localization/zhs` 文本。
- `Shenshen/images/character_forms/human/`、`cat/`：两种形态的图集、枢轴定位清单与选定外形参考。
- `tools/`：Mac / Windows 安装和构建入口。
- `pack/`：资源导出专用 Godot 配置。
- `docs/`：设计、协作与第三方来源说明。
- `local/`、`work/`、`.godot/`、`dist/`：本机工具、参考资料、临时文件或构建结果，均不提交。

## 双机同步

源码私有仓库：`https://github.com/zydjx7/shenshen-sts2-mod`。

Mac 的现有工作副本连接 `origin`；Windows 在本机 Steam 游戏之外的普通目录克隆同一仓库，再运行 Windows bootstrap。每次开工先拉取，完成后提交并推送；同时做不同功能时使用独立分支。不要用网盘同步工作目录、工具缓存或游戏存档。

游戏程序集、反编译结果、工具安装包与存档只留在本机；源码、原创素材、项目说明及版本锁通过 Git 同步。来源与模板说明见 [第三方来源](docs/third-party.md)。
