# 光之魔法少女深深

《杀戮尖塔 2》原创角色模组，供个人使用。内部工程、程序集及模组 ID 统一为 `Shenshen`；目录名称可不同，两台电脑使用同一仓库。

角色有人形、猫形两种互斥形态，规则见 [角色设计](docs/character-design.md)。Windows 接续已实现独立卡池、两套实际持有的基础牌与变形换牌。当前是开发原型；各项代码、构建与实测范围见 [Windows 验证记录](docs/windows-validation.md)。

## 当前可用内容

- 可构建的 C# / Godot 角色工程，以及简体中文、英文文本。
- Mac 交接和本轮 Windows 均已安装项目内 .NET SDK、MegaDot 和反编译工具。
- Mac 与 Windows 的安装、构建、资源打包脚本；本机绝对路径放在忽略的 `local.props`。
- 版本锁、NuGet 依赖锁、统一编码和换行、Git 忽略规则。

70 HP、每回合 3 能量、正常抽牌 5 张；玩家永久持有少女 9 张、猫 9 张及共享变形魔法 1 张（共 19 张），两形态各为 4 张基础攻击、4 张基础防御与 1 张特色牌（光之印记／猫之甩尾）。额外起手的变形魔法为 1 费、保留、结算回手，变猫获得 1 力量，变少女获得 1 敏捷；升级后分别再获得 1 荆棘与固定 4 格挡。变形只弃掉当前形态专属手牌，从另一形态的实际卡牌中补抽同样数量，保留原实例及其升级、费用等状态。牌堆界面暂显示两套牌总数；共享牌参与当前活跃循环是原型选择。燃烧之血、遗物/药水池、卡图、休息点与商店等场景表现仍为占位。资源打包使用独立临时 Godot 工程。

人形已确认 P1「樱粉圣光」少女 v5：白粉金、高腰修长、自然腿部厚度；猫形已确认自然长毛猫 v2，去掉人类发型、衣物和装饰。按后续反馈改为白金发、自然浅笑和较轻描边，少女等比例显示高度试增约 8%，猫形大小保持不变。战斗外观使用真正的 Godot 分件动画，包含待机、眨眼、少女施法/攻击/受击、猫挥爪/受击、倒下和双形态切换；小火球从杖端飞向敌人，到达后结算伤害。选人立绘直接复用动画头部，头像按钮、HUD 和地图 PNG 也从同一原图导出，避免独立生成的脸形/表情漂移。制作来源与各阶段验证边界见 [角色美术与动画](docs/character-art.md)。

## 使用

Mac：

```sh
./tools/bootstrap.sh
./tools/build.sh build
./tools/build.sh pack
```

Windows：

```powershell
./tools/bootstrap.ps1
./tools/build.ps1 build
./tools/build.ps1 pack
```

默认只向 `dist/` 输出，不改 Steam 设置、游戏安装目录或存档。`dist/Shenshen/` 包含本模组，`dist/BaseLib/` 包含匹配的运行依赖。游戏退出后，才可按需将这两个目录复制到游戏的 mods 目录进行测试。

Mac 交接版本已通过编译与资源检查；本轮 Windows 已通过编译打包、212 项真实程序集/Godot 回归（145 项玩法、47 项动画、20 项 UI/透明/同源资源）。确认稿此前已在专用游戏窗口实测：少女完整外形与白皙肤色、施法/攻击/受击，猫的完整四足/尾巴、攻击/受击，双向变形、动作回到待机及暂停遮罩。已修复实机发现的分件负 Z 遮挡，实测白金发、较轻描边和火球飞行/伤害；前一轮再目视确认选人与动画共用原头部的立绘和按钮，退出后 1036 个日常文件哈希无变化。当前保存沿用原版战前/房间边界，不恢复战斗中途快照；更长流程、双端多人和 Mac 新代码仍待验证。完整范围见 [Windows 验证记录](docs/windows-validation.md)，日常协作见 [开发说明](docs/development.md)。

2026-11-06 的新起始牌组、印记逐段附伤、甩尾和全部升级已实装，已部署并启动全新的专用测试局，游戏界面确认 18 张永久牌及新牌加载；用户随后反馈实战试打卡牌未发现问题。此反馈与 174 项自动回归分别记录，完整边界与平台验收继续推进。变形魔法现为真实基础牌，可在原版普通锻造选牌中升级，保存并继承到后续战斗；开场额外移手，不占正常 5 抽。炸毛基础仅首次敌方攻击扣血获得 3 荆棘，升级后才解锁后续扣血与敌方负面各加 1，费用均为 1。印记的时限、施加者范围及固定格挡等实现选择见 [角色设计](docs/character-design.md)。

## 目录

- `ShenshenCode/`：角色、独立卡池、原创牌、形态与战斗机制。
- `Shenshen/`：角色资源和 `localization/eng`、`localization/zhs` 文本。
- `Shenshen/images/character_forms/human/`、`cat/`：两种形态的图集、枢轴定位清单与选定外形参考。
- `tools/`：Mac / Windows 安装和构建入口。
- `pack/`：资源导出专用 Godot 配置。
- `docs/`：设计、协作与第三方来源说明。
- `local/`、`work/`、`.godot/`、`dist/`：本机工具、参考资料、临时文件或构建结果，均不提交。

## 双机同步

源码私有仓库：`https://github.com/zydjx7/shenshen-sts2-mod`。

Mac 的现有工作副本连接 `origin`；Windows 在本机 Steam 游戏之外的普通目录克隆同一仓库，再运行 Windows bootstrap。每次开工先拉取，完成后提交并推送；同时做不同功能时使用独立分支。不要用网盘同步工作目录、工具缓存或游戏存档。

游戏程序集、反编译结果、工具安装包与存档只留在本机；源码、原创素材、项目说明及版本锁通过 Git 同步。来源与模板说明见 [第三方来源](docs/third-party.md)。
